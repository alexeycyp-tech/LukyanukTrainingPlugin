# Changelog

## 1.0

- Reduced the “JUMP BACK” label size while keeping the displayed distance text at its previous size.
- The stopwatch display now appears on the first Enter press. Timing starts at the +5 m start line; the first Space press records the initial pass as the reference when at least two valid samples were collected, then returns to the saved position.
- Preserved the 0.5.17 feature set. The experimental phone Turn History bridge from 0.5.18/0.5.19 is not part of this build.

## 0.5.11 - RBRControls ignition test

- Removed engine RPM capture and restore.
- Added a hash- and code-signature-gated internal RBRControls Ignition call attempt during the frozen restart countdown.
- Added English install and test instructions.
- Runtime behavior remained unverified in RBR.
