LukyanukTrainingPlugin 1.0 - Installation

1. Close Richard Burns Rally.
2. Back up Plugins\LukyanukTrainingPlugin.dll.
3. Extract this archive into the RBR game folder (the folder containing RichardBurnsRally.exe), keeping the Plugins folder structure.
4. Replace the plugin DLL. Keep your existing Plugins\LukyanukTrainingPlugin\LukyanukTrainingPlugin.ini so your button assignments are preserved.
5. Start a stage and use the plugin menu to check or assign Save, Restart, and Jump Back buttons.

QUICK USE

- Press Enter (default Save button) to save a restart position and begin a new timing session. The stopwatch appears immediately; the timed section starts when the car crosses the line 5 m past the saved position.
- Press Space (default Restart button) at the desired finish point. The first timed pass is recorded as the reference if at least two valid samples were collected, then the car returns to the saved position.
- Press Space again to repeat the section and compare the result with the best time.
- Press the assigned Jump Back button to return to the nearest checkpoint behind the car.

Logs: Plugins\LukyanukTrainingPlugin\logs
